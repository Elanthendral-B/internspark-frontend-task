# 📌 Task 3 – Tamil Nadu Weather Dashboard

## Description

A weather dashboard that displays current weather information for different cities across Tamil Nadu.

The application uses the Open-Meteo Weather API and JavaScript Fetch API to retrieve live weather data.

## Available Cities

- Chennai
- Coimbatore
- Madurai
- Tiruchirappalli
- Thanjavur
- Salem
- Tirunelveli
- Erode
- Vellore
- Pattukkottai

## Features

- Tamil Nadu city selection
- Live weather data
- Temperature
- Feels Like temperature
- Humidity
- Wind Speed
- Precipitation
- Weather condition
- Loading indicator
- Error handling
- Refresh weather data
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- REST API
- DOM Manipulation

## API

Open-Meteo Weather API
