# 📌 Task 3 – Tamil Nadu Places Explorer

## Description

A responsive API integration project that dynamically fetches and displays Tamil Nadu city and place information using a public REST API.

The application uses the Open-Meteo Geocoding API and JavaScript Fetch API to retrieve geographical information such as place name, state, district, latitude, longitude and timezone.

Users can search for Tamil Nadu places using the search feature.

## Available Tamil Nadu Places

- Chennai
- Madurai
- Coimbatore
- Dindigul
- Salem
- Tiruchirappalli
- Thanjavur
- Tirunelveli
- Thoothukudi
- Erode
- Vellore
- Kanchipuram
- Kanyakumari
- Karur
- Namakkal
- Sivakasi
- Ramanathapuram
- Virudhunagar
- Cuddalore
- Dharmapuri

## Features

- Tamil Nadu specific places
- Dynamic API data
- Search places
- Filter places in real-time
- Place name
- State information
- District information
- Latitude
- Longitude
- Timezone
- Loading indicator
- Error handling
- Try Again button
- Responsive design
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
